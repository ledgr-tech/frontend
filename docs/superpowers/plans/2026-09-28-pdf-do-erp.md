# PDF do sistema de gestão — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Aceitar e anunciar o PDF de lançamentos exportado do ERP no lado do sistema de gestão (itens 4, 6 e 7 do teste manual de 28/09).

**Architecture:** O upload já manda os bytes do arquivo como estão (`lerBytes`), e a checagem local de colunas só roda para `.csv`, então um PDF passa direto para o backend. O que muda na tela é o `accept` do cartão do sistema, os textos que dizem o formato e a mensagem de recusa, que passa a citar os formatos do lado que falhou.

**Tech Stack:** Next.js 16, React 19, TypeScript, Vitest + Testing Library.

**Spec:** [docs/superpowers/specs/2026-09-28-teste-manual-28-09-design.md](../specs/2026-09-28-teste-manual-28-09-design.md) (itens 4, 6, 7; decisão 7 e B1)

**Branch:** `feature/pdf-do-erp`, empilhado sobre `feature/textos-sem-travessao` (os dois reescrevem a frase da visão geral e o passo II da landing). O PR sai com base nesse branch e troca a base para o `develop` quando o de textos entrar.

## Global Constraints

- PDF só no lado do sistema de gestão: o banco continua OFX ou CSV. O teste pediu o "PDF de lançamentos do ERP".
- Em 28/09 o time confirmou que o backend aceita PDF. O `develop` do backend no GitHub ainda lista só `.ofx` e `.csv`; este PR entra quando o backend com PDF estiver no ar, senão o upload de um PDF recebe a recusa do backend.
- Sem travessão no meio das frases (decisão 6 da spec).
- O limite de 4MB vale para o PDF também.
- Antes de cada commit: `npm run test && npm run lint && npm run build` (CLAUDE.md).

## Review Focus

1. **PDF com o nome em maiúsculas** (`RAZAO.PDF`): passa como PDF, sem ser lido como CSV. Teste na tarefa 1.
2. **PDF recusado pelo backend** (status `erro`): a mensagem cita CSV ou PDF, os formatos do lado do sistema, e não OFX. Teste na tarefa 1.
3. **Recusa do lado do banco**: continua citando OFX ou CSV. Teste na tarefa 1.
4. **PDF acima de 4MB**: barrado antes de subir, como os outros. Coberto pelo teste de tamanho que já existe (a regra não olha a extensão).
5. **Seletor de arquivo**: o do banco não passa a aceitar PDF. Teste na tarefa 1.
